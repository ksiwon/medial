# 전시 영상 3안 설계 — 대화 장면을 영상 생성 AI로

상태: 설계 초안(2026-10-15). 1안(`…_2026-10-13.mp4`)과 2안(`…_2026-10-14.mp4`)은 확정본이라 건드리지 않는다. 3안은 새 이름·새 폴더로 만든다.

## 1. 무엇을 만드나

한 사이클 = 시연 영상이 따라가는 한 경로: 1일차 → 첫 번째 선택(체면) → 2일차 → 첫 번째 선택(이웃부터) → 3일차.
이 경로의 대화 장면 7개(기록의 `featured`)를 영상으로 바꾼다. 인트로·아웃트로·평가·선택 화면은 그대로다.

## 2. 한 줄의 영상은 이렇게 만든다 (시험으로 확정)

| 항목 | 정한 값 |

| 목소리 | 모델이 만든 소리를 그대로 쓴다(사용자 선택: 목소리·사투리가 더 좋음). 우리 음성 파일은 목소리 참조로만 넣는다 |

| 확인 | 만든 뒤 소리를 받아 적어 대사와 비교, 틀린 줄만 다시 만든다 |

## 4. MEDial의 줄은 어떻게 보이나

MEDial은 얼굴이 없는 전화 목소리다. 장면 1·3·5·6·7의 MEDial 줄(16줄) 동안 화면에는 상대(주민)가 전화를 들고 듣는 영상이 나온다.
- 장면마다 8초짜리 "듣는 영상" 1개를 만들어 이어 쓴다(MEDial 줄 길이에 맞춰 자르고, 줄이 길면 앞뒤로 되돌려 재생).
- 소리는 지금의 MEDial 음성(2안과 같은 파일)을 그대로 쓴다.
- 말풍선 자막은 지금처럼 둔다.

## 5. 만들기 전에 필요한 것

1. 기준 인물 4명 추가: P9, P12, P7, 보건소 간호사 (+ 장면 7의 쓰러진 P8). 기존 그림을 보고 묘사 → 3~4장 뽑기 → 가장 닮은 것 선택. (P6, P1은 끝남)
2. 장면 7은 두 사람(P7이 P8에게 심폐소생)이 한 화면이라 가장 어렵다. 먼저 480p로 구도를 확인한다.
3. 배경 그림 연결: PATROL, HOME, CLINIC.desk, TOWN 각각이 전화 통화 장면의 장소로 어울리는지 확인.

## 6. 앱에 붙이는 방법

- 영상 파일은 `local-data/video/clips/`(git 밖)에 두고, 음성처럼 `manifest`에 `speaker|text → 영상 파일`로 연결한다.
- 화면: 장면의 가운데 그림 자리에 영상을 재생하고, 줄이 바뀔 때 해당 줄의 영상으로 바꾼다. 말풍선·타임라인·판단 패널은 그대로.
- 영상이 없는 줄은 지금처럼 그림을 보인다(그래서 3안은 일부 장면만 영상이어도 동작한다).
- 3안은 켜고 끄는 스위치(예: 주소 `?video=1`)로 두고, 끄면 2안과 똑같이 나온다.
- 영상의 소리는 대사 음성을 대신한다(기존 음성 파일은 재생하지 않는다). MEDial 줄은 기존 음성.
- 줄 길이는 영상의 말 끝(소리가 끝나는 곳)에 맞춘다. 끝 무음은 자른다.

## 8. 단계

1. 기준 인물 4~5명 뽑기 → 사용자 확인
2. 장면 7(위급)의 구도를 480p로 시험 → 확인
3. 장면 1~7을 480p로 한 번 전부 만들어 구성·대사·구도를 확인(약 $35) → 확인
4. 확정된 줄만 1080p로 만든다(구도가 바뀌므로 줄마다 한 번 만들어 보고 이상한 줄만 다시)
5. 앱에 연결, 3안 녹화(새 이름), 2안과 비교

## 9. 위험

- 해상도를 바꾸면 같은 씨앗값이라도 구도가 조금 달라진다 → 4단계 결과를 보고 줄별로 고른다.
- 모델이 "메디얼"을 매번 다르게 읽을 수 있다 → 받아쓰기로 확인하고 필요한 줄만 다시 만든다.
- 장면 7(두 사람 중 하나가 누워 있음)은 어색하게 나올 수 있다 → 안 되면 P7만 나오게 하고 P8은 그림으로 처리.
- 기준 인물은 2안의 얼굴과 같지 않고 비슷한 새 얼굴이다(필터 때문).
- 한 줄의 영상 소리는 모델의 소리이므로, 같은 인물의 목소리가 줄마다 약간 달라질 수 있다.
